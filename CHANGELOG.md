# Changelog

All notable changes to this project are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

**Reconstructed 2026-08-27** from git history as part of onboarding to
`infrastructure/WEBAPP_PROJECT_STANDARD.md` (§3) — not generated by `/deploy`,
which doesn't exist for this repo yet. Versions `1.0.0`–`1.5.0` correspond to

## [Unreleased]

### Added
- Minimum-person-count filter, also applied to the compare option list.
- Password gate (`deploy_auth/`) in front of the public FTP target — fail-closed, signed
  expiring cookie, separate passphrase from `housebuycomparison`'s.
- Release snapshotting and `--rollback` for the public FTP target — every deploy snapshots the
  gated bytes it uploads, keeping the last 5.
- Onboarded to `infrastructure/WEBAPP_PROJECT_STANDARD.md`: `homelab.yml`, `VERSION`,
  `CHANGELOG.md`, `deploy.config.example`, shared `.claude/skills/{deploy,rollback}` wrappers,
  Dependabot, and a pytest suite (previously no automated tests existed).

### Changed
- Ratings normalised to a common 0–10 scale across all brokers.

### Fixed
- Fewo rating parsing and URL logging.
- Sticky scrollbar pinned to the bottom of the viewport on desktop.
- Lint warnings.
- A full scrape run that yields zero houses now aborts instead of silently overwriting the
  published site with an empty one.
- CI now actually runs the test suite — `tests/` wasn't importable under bare `pytest` (only
  under `python -m pytest`, which isn't what CI or `TEST_CMD` run), so 0 tests were collected.

## [1.5.0] - 2026-03-30

### Added
- Bus stop distance auto-calculation from POIs, plus manual bus-track overlays on maps.
- Per-house override for sled-run/Loipen search parameters (`loipen_radius_m`, manual `loipen_urls`).
- Support for houses with no broker URL (`direct_url` only, all fields manual).
- Fully-documented template entry in `input.json` for adding new houses.
- `on_house_scraped` callback with partial-save support, so progress isn't lost on a mid-run failure.

### Fixed
- Bot-detection work-around improvements for fewo-direkt scraping.
- Loipen override ignoring the curated manual URL list.
- Booking.com parser failing on listings with multiple properties.
- Bus track colour on the map.
- URL cleanup (stripping stale session/tracking parameters) and a Loipen discovery circuit breaker.

## [1.4.0] - 2026-03-28

### Added
- House comparison feature (select houses, view a side-by-side diff table).
- Test deployment script (`deploy-test.sh`/`.ps1`, uploads to a non-live filename).
- Sled-run/Loipen data via the Overpass API.

### Fixed
- Error handling for parsing failures.
- User-agent rotation for scraping.
- Chrome usage/session handling.
- Comparison table readability.
- Lint warnings.

## [1.3.0] - 2026-03-28

### Added
- New broker parser: interhome.de.
- Train track overlays on maps for car-free villages.
- Python linting (pylint) in CI.

### Changed
- `input.json` layout refactored to a house-centric structure.
- Area labels improved.

### Fixed
- Missing info-text translation.
- Hamburg and Karlsruhe (Bavarian dialect family) language variants.
- Sled route length calculation.
- fewo-direkt parsing of rooms and country.
- Malformed bed descriptions.
- Distance format.

## [1.2.0] - 2026-03-28

### Added
- Multi-language support (translated UI).
- Deployment scripts for Unix and Windows (FTP upload).
- New broker parser: huetten.com.
- Distinct visual style for unavailable houses.

### Changed
- Version indicator moved to a chip at the top of the page.

### Fixed
- ChromeDriver invocation.
- Mobile scroll issue.
- Remaining hard-coded UI strings.

## [1.1.0] - 2026-03-23

### Added
- Country flag indicator per house.
- Error highlighting on the page for scrape failures.
- Per-house notes field.
- Sled runs shown on the house map (not just the overview map), where available.

### Changed
- Bedroom configuration parsing improved.
- Price-per-person estimates adapted for larger group sizes.

### Fixed
- fewo-direkt scraper breakage.
- Parser handling of a house with multiple listing entries.

## [1.0.0] - 2026-03-23

### Added
- Initial static site generator: scrapes house listings (fewo-direkt, booking.com) and sled run
  data (rodelwelten.com, outdooractive.com), renders a comparison page via Jinja2.
- Google Maps links and general UI polish.
- Sleigh/sled-run summary per house.
- Overriding scraped house values from `input.json`.
- Price-per-person display, huts info.
- Overview map grouping houses by location, with sled run tracks overlaid.
- Public transit icon and nearest sled-run info on house cards.
- New broker parser: outdooractive.com.
- Support for scraping a single house (`--house`), skipping others.
- Version chip in the page footer.

### Fixed
- fewo-direkt parser breakage.
- Duplicate markers for houses sharing the same coordinates.
- Multi-GPX-track handling for rodelwelten.com routes.
